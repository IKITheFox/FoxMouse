# 安装语言选择框主题修正

上一轮实际截图显示：深色 MaintenanceWindow 已设置 ComboBox BackColor/ForeColor，但原生默认绘制仍出现白色选择区域。

本轮新增共享 `installer/ThemeAwareComboBox.cs`，保留 ComboBox 下拉选择和无障碍/键盘行为，用 FlatStyle.Flat 与 OwnerDrawFixed 绘制所选文字及列表项。普通区域使用所属窗口的背景/前景，展开选中项使用 Windows Highlight/HighlightText，禁用时使用 GrayText，并绘制焦点指示。

Deployment 与在线 Bootstrap 均使用此控件；引导器仍可用 Windows 自带 C# 5 编译器构建，不新增待安装运行库依赖。MaintenanceWindow 使用既有动态主题监听；Bootstrap 新增 WM_THEMECHANGED / WM_SETTINGCHANGE / WM_SYSCOLORCHANGE 响应。

验证：

- 新增 3 项真实 WinForms 控件位图测试，深灰/白色/黑白配色下检查关闭选择框中部背景像素；同时验证中文/英文选择仍可切换。
- 初次隐藏窗口的 DrawToBitmap 返回透明像素，被测试拒绝；改为先显示并更新测试窗口后取样，3 项通过。没有把空白截图算作主题通过。
- Deployment 共 147 项测试通过。
- Framework64/v4.0.30319/csc.exe 编译包含共享控件的 Bootstrap 成功。

仍待：实际安装器展开列表、完整文字高度、真实系统高对比度及运行时主题切换的截图验收。黑白模拟配色测试不等同真实系统高对比度验收。此前离线发布目录及在线候选不含本轮修复，最终交付需要重新打包，不覆盖历史产物。
