本报告记录 v0.2.0 相对已通过的 v0.1.0 基线所增加的验收范围。以下证据

## 本轮目标

- 托盘右键菜单改为 Windows 11 风格圆角弹出界面，跟随浅色、深色、强调色
  和高对比度，并保留键盘、焦点和 DPI 可用性。
- Settings/About 启动不再以“进程已创建”作为成功条件；外部 WinUI 宿主需
  报告窗口就绪，崩溃、提前退出或超时时回退到内置 WinForms 窗口。
- 放大光标 overlay 每帧提交后重新恢复 topmost z-order，避免被普通窗口或
  应用自身的 topmost 窗口长期遮挡，同时保持不激活、不拦截点击。
- Windows 安全桌面仍是明确的系统边界：FoxMouse 不跨越 UAC 同意界面、
  登录界面或锁屏，也不尝试绕过该保护。
