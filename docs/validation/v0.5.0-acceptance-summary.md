## 退出整链路审计及待确认动作

已复核生产路径：ModernTrayMenuForm.ExitRequested → HandleExitClicked → ExitThread → ShutdownAsync；先释放引擎并恢复系统光标，再等待 SettingsShutdownChannel.RequestAsync，最后移除托盘并退出主消息循环。该请求不会因用户考虑保存时间较长而超时强杀窗口。现有生命周期 smoke 明确以 `_lifecycleSmokeMode` 跳过此跨进程请求，因此其通过不等于正式托盘→设置→主进程完整链路通过；独立设置 IPC 测试则覆盖请求后用户选择的行为。

2026-09-15 已获用户隔离安装确认，并完成中文应用安装完成页的直接按钮验收，见新增证据。干净 Windows 测试环境仍需用户提供或明确授权配置，不能删除开发机共享运行库来模拟。其他剩余验收仍未完成，不因单项通过而宣布全部完成。
