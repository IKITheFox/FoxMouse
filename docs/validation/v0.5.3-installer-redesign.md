# FoxMouse 0.5.3 安装界面更新

## 实施范围

按最新单页渲染图的布局方向实施，而非之前的紧凑九宫格设计：

- 默认客户区 680×520，32 像素逻辑留白；内容左对齐、按钮右下对齐。
- 标题栏保留正式 FoxMouse 图标，移除维护页左侧的大 Logo 占位。
- 普通主题去除卡片、按钮和语言选择框描边，使用底色区分控件；主按钮为 FoxMouse 橙色，确认卸载为红色。
- 标题栏、正文随 Windows 深浅主题变化；高对比度和键盘焦点保留可访问性边界。
- 在线首页保留语言、目录、更改、继续、关闭；目录确定后才处理依赖。
- 组件下载、组件安装、准备、失败和需要重启使用各自标题与提示，隐藏无关首页控件；下载显示真实数据和橙色进度。
- 安装、修复、升级、卸载运行状态使用独立标题；卸载确认显示安装位置、保留设置选项和恢复系统光标提示，不增加滚动条。
- 四类成功操作都等待用户点击“确定”。操作中已请求退出时，仍先结束事务再退出。
- 维护失败页增加重试及打开日志。卸载重试仍先确认。详细错误保存在 InstallerLogs，未用模拟错误内容替代实际异常。
- 保留中英文与路径安全检查，不新增安装依赖。

视觉稿是布局参考，不是逐像素截图承诺。下载组件名称、安装路径、错误原因、版本及保留设置结果均来自实际状态。错误详情通过日志/提示查看，并非渲染图中的折叠式详情控件；运行中“关闭”继续采用安全延迟退出，而不是强杀或完全禁用。

## 用户复测

1. 用新包检查首屏布局和系统浅色/深色切换。
2. 更改目录后继续，核对目录正确传递；缺依赖机器检查下载数值与普通控制台隐藏。
3. 安装、修复、升级、卸载成功后，应停留在对应完成页，点击确定退出。
4. 卸载确认中检查完整显示、保留设置选项与返回操作。
5. 在不同屏幕/缩放率检查文字、长路径省略及按钮；高对比度模式可保留必要描边。

本轮没有在干净缺依赖机器上重新安装系统运行时，也未覆盖所有物理显示器组合；以上仍需实机验收。
