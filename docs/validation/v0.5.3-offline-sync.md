## 尚需独立环境验收

以上结果来自开发机，不能作为干净 Windows 完全断网验收的替代。

1. 在支持的干净 Windows x64 虚拟机快照中断开网络，运行本包。
2. 分别检查中英文、浅深色主题；选择自定义目录，确认末尾仅添加一次 FoxMouse。
3. 安装完成后停留完成页；点击“确定”再退出。启动 FoxMouse，打开设置并预览光标效果。
4. 再运行安装器执行修复，确认同样等待完成确认。
5. 分别验证根目录卸载入口和 Windows 已安装应用入口，检查保留/删除设置选项。
6. 检查 100%、150%、200% 缩放及跨显示器移动后的布局；确认无文字遮挡或滚动条。

体积较在线版大是自包含运行库的取舍，本次不承诺离线包显著缩小。
