# 1.0.0 Beta validation

Date: 2026-09-16.

## Version contract

- Numeric product/deployment version: `1.0.0`.
- Assembly and file version: `1.0.0.0`.
- Informational/product metadata: `1.0.0-beta` (build metadata may be appended by the SDK).
- User-facing version: `1.0.0 Beta`.
- Online bootstrap native version metadata is generated from the same build properties.
- Existing numeric installation records remain compatible; older versions are not relabeled Beta.

## Validation

- Full Release solution suite: 534 passed (Core 107, Deployment 165, Settings 65, Platform 197).
- The first suite run failed in the real desktop locator composition check. The isolated re-run passed, then the complete suite passed without changing or disabling the test. This is not evidence that every desktop interference scenario is resolved.
- Offline build and artifact/lifecycle gates passed. Actual 150% DPI installer capture was inspected and displays `FoxMouse 1.0.0 Beta`.
- Online artifact validation and isolated graphical lifecycle passed, including fresh install, repair, maintenance, uninstall confirmation, failure exit behavior, and quiet uninstall.
- Online lifecycle evidence ID: `a9986445eeb845ca95786330bffa56e4` (under the temporary FoxMouse-InstallerLifecycle directory).
- Documentation-only repackaging uses `-SkipValidation` after the complete suite passed; this skips the repeated solution tests, not the artifact/lifecycle gates.

## Limits

Artifacts remain unsigned. These checks ran on a development machine with installed runtimes. Clean Windows with missing dependencies, completely offline operation, and comprehensive mixed-DPI/multiple-monitor acceptance remain separate checks.

## Repository documentation

README, contribution guidelines, and security policy provide Chinese and English entry points, following FoxFetch's organization but describing FoxMouse-specific behavior. The remote repository's existing GPL v3 LICENSE is retained unchanged; the old preview-only notice is superseded. Security policy documentation does not enable GitHub private vulnerability reporting.

No private key, generated executable, build cache, or runtime payload is included in the source commit. Installers are delivered separately, not committed to source history.
