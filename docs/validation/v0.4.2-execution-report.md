## 本轮需求完成情况

- “原生”模式放大当前系统光标本体；“定位环”是明确可选的兼容模式，不再用
  圆圈冒充光标放大。动画使用独立放大/弹性回缩状态，快速摇动触发与误触抑制
  均有确定性轨迹和状态机测试。
- 覆盖层逐帧恢复 `HWND_TOPMOST` 且不激活，按显示器 DPI/光标热点重新计算几何；
  8K 光标夹具使用高分辨率源，避免先低分辨率栅格化后再放大。
- Guard、租约、所有退出路径和故障边界会恢复系统光标。预览结束的静止光标
  刷新固定为 `ShowAcknowledged -> RemoveOverlay -> RefreshNativeCursor`，避免必须
  移动鼠标后才重新出现。
- 设置界面采用 WinUI 3 与系统主题资源；常规说明和常驻详细描述已移除，说明
  改为悬停帮助并保留无障碍文本；倍率不补尾零；模式名为“原生 / 定位环”；
  滑条端点、10 秒中性保存提示和精简 About 均已落实。
- 用户提供的 FoxMouse Logo 已生成浅色、深色和两种高对比资源，设置、托盘、
  About、Setup 和卸载器根据 Windows 主题选择对应资源。
- Setup 支持全新安装、升级、修复和卸载；安装根目录包含
  `FoxMouse.Uninstall.exe`，HKCU“已安装的应用”包含图形卸载/修改入口及同步
  静默卸载入口。
- 点击安装位置可选择父文件夹；策略会规范化路径并只追加一个 `FoxMouse`。
  已安装状态的修复和卸载始终沿用注册且校验过的自定义位置。
- 安装、升级、修复和卸载成功后自动退出，不再弹出阻塞式完成框；关闭按钮、
  标题栏关闭和 Esc 共用关闭状态机，事务中请求关闭会等待提交或回滚结束。
- 安装、维护和卸载确认采用互斥单页状态；无滚动条、无按钮换行，长路径省略
  显示但保留完整提示，长错误被限制在固定区域且完整内容仍可通过 Tooltip 和
  无障碍描述取得。

## 自定义位置与完整生命周期

最终门禁实际执行：

1. 在含空格的隔离父目录中打开图形 Setup，验证“更改”入口与唯一
   `FoxMouse` 叶目录，然后安装并自动退出；
2. 不再传入父目录，重新运行 Setup 并从 Installed Apps 状态发现自定义根，完成
   同版本修复；
3. 删除已安装的 `README.md`，由根卸载器使用状态绑定的缓存修复，并验证恢复前后
   SHA-256 相同；
4. 校验安装状态、缓存 ZIP 和 sidecar 三方哈希一致，快捷方式、DisplayIcon、
   InstallLocation、ModifyPath、UninstallString 与 QuietUninstallString 全部指向
   同一规范化根；
5. 进入卸载确认页后关闭，证明没有提前卸载；随后执行根卸载器 handoff 并等待
   原子事务结果和 Cleanup 结果；
6. 强制制造 Guard 缺失，静默 ARP 卸载正确返回 1 且保持安装状态；恢复后返回 0；
7. 再次安装并选择删除设置，确认设置目录没有被状态文件重新创建；
8. 确认默认安装根从未使用、所选父目录的同级哨兵文件存活，最终运行对应的临时
   根、测试注册表键、维护 host、staging、backup、负向 PNG 和产品进程均为 0。
