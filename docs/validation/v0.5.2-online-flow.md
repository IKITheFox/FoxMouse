# FoxMouse 0.5.2 在线安装流程验收

## 修改

- 在线安装首屏提供语言、安装位置和“更改”按钮。点击继续后才检测、下载和安装依赖。
- 选择父目录后自动追加 FoxMouse；选择已经以 FoxMouse 结尾的目录不会重复追加。
- 新安装通过 --install-parent 将选择传给正式安装界面，部署引擎仍执行路径安全检查。正式安装界面保留最终确认和调整机会。
- 检测到当前用户的安装注册项或默认目录中的 FoxMouse 时，首屏显示原位置，禁止更改，不向维护流程传递新目录。注册信息只用于首屏展示，部署引擎仍验证安装身份。
- 组件使用 Hidden 窗口方式启动并保留静默参数，正式 FoxMouse 安装窗口使用 Normal；保留系统权限确认机制。
- 提示简化为“选择安装位置，继续后自动补齐组件。”和“就绪”，同步英文。

## 用户实机复测

1. 在缺少组件的干净 Windows 中打开在线安装器。首屏应能选中英文和安装目录，尚未开始组件下载。
2. 选择一个带空格的可写父目录，例如 D:\Test Apps；显示位置应为 D:\Test Apps\FoxMouse。选择 FoxMouse 文件夹自身，不应产生 FoxMouse\FoxMouse。
3. 点击继续，观察检测、下载进度、组件安装。普通组件控制台应隐藏；若请求管理员权限，系统权限确认正常显示。该控制台行为尚未在缺依赖机器上复测，第三方组件自行创建的窗口仍需实际验证。
4. 后续正式安装页应显示相同位置。完成安装后点击确定退出。
5. 已安装情况下再次运行，应显示原目录且不允许在引导页迁移目录；确认能进入维护界面。

本轮未在用户系统安装、卸载运行时，也未把缺依赖实机验证标记为通过。安装包未签名、未上传 GitHub。
