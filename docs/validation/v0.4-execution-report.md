## 安装、修复与卸载验证

发布门禁实际启动最终 Setup 和卸载器，但将文件与 HKCU 注册定向到严格隔离的
`%TEMP%\FoxMouse-InstallerLifecycle-<GUID>` 和
`HKCU\Software\FoxMouse\Tests\InstallerLifecycle-<GUID>`：

1. 全新安装并检查 App、Guard、Settings、根卸载器、Cleanup、真实 `.lnk` 和 ARP 字段；
2. 使用 Setup 执行同版本修复；
3. 删除已安装的 `README.md`，从根卸载器读取已安装缓存修复，并确认恢复前后 SHA-256 完全相同；
4. 验证缓存 ZIP、`.sha256` sidecar 和 `.foxmouse-install.json` 三方哈希绑定；
5. 通过根卸载器的 parent/child handoff 卸载，并等待原子结果与 Cleanup 完成；
6. 强制缺失 Guard，确认同步静默 ARP 卸载返回 1 且安装状态未变；恢复 Guard 后返回 0 并卸载；
7. 再安装并选择删除设置，确认 SettingsRoot 没有被状态文件重新创建；
8. 确认临时 host、cleanup worker、staging、backup 和隔离注册表键均无残留。

根 GUI 卸载入口采用 launcher 语义：确认临时维护 host 已就绪后即可返回，真实
完成状态通过原子结果文件提供。`QuietUninstallString` 指向安装目录外的稳定维护
host，并同步返回真实事务退出码。Cleanup 是 27,648 字节、版本 0.4.0.0 的受
约束 companion；它只删除已验证的普通文件和空目录，不使用重启删除。
