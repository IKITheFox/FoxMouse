## v0.3.0 关键改动

- 普通运行故障不再永久锁死效果。状态机按 250 ms 起、最高 5 s 的指数退避
  进入半开探测，光标资源、设备拓扑、overlay、Guard 或心跳恢复后自动回到
  正常状态；只有用户主动禁用或明确的永久错误才会锁定。
- Guard 使用 1.2 s 的实际隐藏租约，独立监督线程每 250 ms 检查。只有当前
  效果代次在最近 500 ms 内成功提交过 overlay 帧才允许续租；UI 卡死、代次
  不一致或渲染停顿会优先执行系统光标恢复。
- 隐藏确认与具体 Guard 实例和效果代次绑定，并设置 500 ms 有界交接窗口，
  消除了“Guard 已隐藏、UI 尚未确认”和监督线程恢复之间的竞态。
- Raw Input 增加缓冲区排空、同毫秒 8 kHz 时间处理、多设备活动聚合，并使用
  Windows 系统拖拽阈值区分真实拖拽；普通点击不会再无条件暂停效果。
- 动画改为解析阻尼弹簧。收缩具有受控弹性，按时间求解而非按帧累积，因此在
  不同刷新率下保持近似一致，并要求连续稳定帧后才结束。
- 当前光标优先加载与最大倍率匹配的 `.cur`、`.ani` 或系统高分辨率资源；
  bitmap、内存 DC 和局部 DIB 持久复用，最大表面为 2048×2048，不分配整屏
  8K 缓冲。窗口 DPI、负坐标、热点和跨显示器几何均有确定性测试。
- 继承并复验 v0.2 的原生主题设置界面、Settings/About ready/fallback、
  Windows 11 托盘菜单、进程搜索选择器和每帧 topmost 恢复。

## 运行安全核对

门禁前后，用户已安装的 FoxMouse 仍是同一组进程：App PID 20956、Guard
PID 18688，路径均位于 `%LOCALAPPDATA%\Programs\FoxMouse`，启动时间未变。
本轮没有替换、关闭或真实隐藏其系统光标。

自动门禁的 `allowRealCursorHide` 为 `false`。这是有意的安全边界：真实隐藏
只能在操作者明确同意的交互式 Windows 桌面上，以 Guard 前置/后置恢复包围
后执行。它不影响代码、fake Guard、租约、失效恢复和发布包门禁的 PASS，
但在面向公众发布前仍应完成一次人工真实光标验收。
