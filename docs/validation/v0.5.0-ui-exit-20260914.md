## 发现并修复

真实跨进程退出请求直接调用 Window.Close，绕过 AppWindow.Closing 的保存确认；即使存在未保存修改，也直接退出。这说明策略单测不足以覆盖实际窗口调用路径。

MainWindow 改为共享 ConfirmCloseAsync：普通关闭事件与全局退出都显式进入确认逻辑。Window.Close 只在已确认或无改动时调用。已打开的对话框不会重复创建；全局退出标志仍参与用户选择的最终判断。
