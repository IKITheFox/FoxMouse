# 0.5.0 在线安装器干净 Windows 验收

状态：待提供干净测试环境。当前开发机已有运行库，不能充当“首次缺依赖安装成功”的证据。

## 环境与隔离

- 使用可丢弃的 Windows x64 虚拟机或专用测试机，记录系统版本、显示缩放和 CPU 架构。
- 保存空白快照；不得在用户日常电脑上卸载共享运行库来模拟缺失。
- 确认没有 .NET Desktop Runtime 10.0.11 或兼容补丁，以及安装器要求的 Windows App Runtime 包。运行在线安装器 `--probe` 应返回 2；保存退出码与系统清单。
- 仅传入待验收的安装程序，记录文件 SHA256；不要共享主机文档、凭据或 SSH 私钥。
- 联网与管理员审批由测试环境所有者允许；不得绕过 SmartScreen、安全或权限提示。

## 验收矩阵

| 场景 | 必须观察到的结果 |
|---|---|
| 首屏中文 / English | 第一页即可切换；后续安装页一致，文字完整且按钮有效 |
| 两项依赖都缺失 | 检测缺失 → 微软源下载并验证 → 组件安装 → 再检测 → FoxMouse 安装界面 |
| 只缺 .NET / 只缺 App Runtime | 只下载缺少的组件，已有兼容版本不重复安装 |
| 依赖均存在 | 不下载运行库，进入应用安装界面 |
| 断网或下载中断 | 不启动不完整文件，不声称成功，恢复网络后可重试 |
| 下载时关闭 | 取消下载并关闭；不执行残留文件，不留下运行中的安装器 |
| 组件已开始安装时关闭 | 不强杀组件安装进程，等待其结束后退出；不继续安装 FoxMouse |
| 返回 3010 / 1641 | 明确提示重启，当前窗口不可继续或重试；关闭保留重启退出码，不自动重启电脑 |
| 组件返回失败或安装后仍检测不到 | 不进入 FoxMouse 安装，不报成功，提供错误提示 |
| 完成应用安装 | 显示已完成，点击确定才退出；首次启动语言采用安装选择 |
| 重跑、修复、卸载 | 安装位置与版本识别正确；修复保留设置；卸载清除程序及应用列表注册，按选择处理个人设置 |

## 安全与失败注入

哈希错误、非法下载来源、重定向、取消、断流、长度超限由本地隔离自动测试覆盖；不得通过修改微软实际组件制造主机风险。重启返回码的分支可用隔离测试替身验证，但必须明确标注为模拟，不算实际组件安装成功。

## 留存证据与通过判定

记录安装包哈希、干净环境清单、每次操作语言、退出码、下载/安装日志、关键窗口截图、安装后 probe=0、设置窗口与光标效果启动结果。

只有缺依赖机器真实完成下载、组件安装、再检测、FoxMouse 安装与运行，才可写“干净环境在线安装通过”。本机 CLI 安装、策略单测、编译成功或真实下载哈希通过均不能替代此项。
