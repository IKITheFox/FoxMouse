## 外部发布门禁与限制

- `signed=false`：当前制品未做 Authenticode 签名或可信时间戳。
- `allowRealCursorHide=false`：无人值守 M5 未隐藏真实系统光标；正式发布前需在
  明确授权的交互桌面执行恢复包围的真实 hide/show。
- 干净 Windows 10/11 VM 点击式安装、Windows“已安装的应用”入口、旧发布包
  原位升级、浅色/高对比实机和实体多显示器/HDR/8K 矩阵均为 NOT RUN。
- FoxMouse 子树当前未纳入父工作树的可验证提交，因此没有诚实可用的 Git freeze
  标识。最终二进制由本报告中的证据目录、精确长度和 SHA-256 固定；公众发布前
  应将源码纳入版本控制并创建签名 tag。
- UAC、安全桌面、登录/锁屏以及受保护或独占表面是 Windows 系统边界，用户态
  overlay 不能承诺字面意义上的“永久不失效”。
