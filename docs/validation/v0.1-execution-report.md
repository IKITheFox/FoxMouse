## 交付结果

FoxMouse 已实现为 Windows 11 x64 每用户托盘应用。快速往返摇动鼠标或
触控板指针时，它围绕当前 Windows 光标的真实热点平滑放大，停止后平滑
缩回。单次高速直线移动不会触发。应用不注入输入、不移动指针，也不改写
系统光标方案。

高保真模式由独立 Guard 进程管理原生光标的隐藏、恢复和超时租约。无法
安全捕获或替换光标时，高保真模式保留原生光标且不绘制定位环；定位环只
属于用户明确选择的兼容模式。Raw Input 设备到达通知不再被误判为设备
丢失，解决了启动后快速摇动不触发、总是进入兼容定位效果的根因。

首选设置界面现为独立单实例 WinUI 3 宿主，使用 Windows 系统主题资源、
NavigationView、标准控件及可用时的 Mica；高对比度或不支持 Mica 时回退
到系统实色。WinUI 宿主不可用时仍可打开主题化 WinForms 设置和关于窗口。

## macOS 网络基线与剩余边界

Apple 当前文档确认：快速移动鼠标或触控板手指会让指针暂时变大；历史发布
材料与公开实机演示支持“快速往返、停止后缩回、放大时仍可操作”的产品语义。
Apple 没有公开触发阈值、最大倍率、增长/回落时长或 easing，普通屏幕录制还
可能无法捕获系统光标效果。因此当前完成的是语义对齐和可调工程实现，不
宣称数值上已经“一模一样”。精确感知对齐仍需当前 macOS 26.x 实机、确定性
HID replay 与外部 120/240 fps 相机；方案见 `docs/macOS-web-baseline.md`。

其他公开边界：

- 物理多屏、全部 mixed-DPI/刷新率/主题组合仍需目标硬件认证。
- sustained 8 kHz 实体鼠标与不同厂商触控板仍需手感和误触率采样。
- 少数 ANI、XOR 或应用自行绘制的光标不能等价复制；此时高保真模式保留
  原生光标并且不会显示圆环。
- WinUI 进程列表当前使用稳定的字母 monogram；WinForms fallback 可读取时
  显示 EXE 图标。
- 当前发布物未签名，Windows 可能显示信誉警告。
