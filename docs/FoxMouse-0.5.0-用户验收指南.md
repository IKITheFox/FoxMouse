# FoxMouse 0.5.0 用户验收指南

交付日期：2026-09-15。此版本为候选测试版，并非全部实机验收通过的正式版。完整 Debug/Release 自动测试均为 515 项通过；中文应用安装完成页已经直接验证。其余项目请按下表反馈，未测试请填“未测”，不要当作通过。

## 一、使用哪个包

- 在线安装包（约 31.2 MB）：用于日常联网安装，以及干净 Windows 缺依赖验收。检测到缺少组件时需联网下载安装。
- 离线安装包（约 254 MB）：包含运行组件，适合不方便联网时测试 FoxMouse 本身；不能用它证明在线缺依赖下载流程通过。
- 两个包都是 Windows x64、0.5.0，均未签名。如果 Windows 安全机制阻止运行，请记录提示并反馈，不要关闭安全软件或绕过拦截。
- 请先退出旧版 FoxMouse，避免两个版本同时控制光标。正式机器升级前备份原设置；完整安装、修复、卸载测试优先在虚拟机进行。选择其他安装目录本身不等于隔离个人设置或应用注册。

## 二、干净 Windows 在线安装

使用无开发工具、未预装所需运行组件的 Windows 11 x64 虚拟机，安装前保存快照。不要卸载日常电脑的共享运行库来模拟缺失。

1. 只复制在线安装包，记录系统版本、架构及显示缩放。
2. 启动安装器，确认第一页可以选择简体中文 / English。
3. 确认它识别出缺失的组件，再继续；已有组件的机器不能作为此项证据。
4. 观察下载、组件安装、重新检测，随后进入 FoxMouse 安装页。按系统正常权限流程操作；若被阻止，请记录，不绕过。
5. 点击安装位置选择一个父文件夹，确认最终目录自动追加 FoxMouse；已选择 FoxMouse 文件夹时不要重复追加。
6. 完成后应显示“已安装完成”，等待至少 10 秒，确认窗口不自动消失；点击“确定”后安装器退出。
7. 打开 FoxMouse，确认程序、设置和光标效果正常，首次语言与安装选择一致。
8. 再运行安装包，确认已有组件不重复下载。同版本应提供修复/卸载，修复后原设置保留。

额外场景（建议每组从快照重新开始）：

- 断网或中断下载：应给出错误而非成功，不启动不完整组件；恢复网络可重试。
- 下载时关闭：应停止下载并退出；不能继续悄悄安装。
- 组件正在安装时关闭：可以等待组件结束，但不能强杀系统组件安装或继续安装 FoxMouse。
- 若组件要求重启：应明确提示，不假装成功；重启后重新运行安装器可以继续。若没有遇到重启条件，填“未触发”，不要填写实测通过。
- 中文、英文各完成一次；条件允许时测试“仅缺一种组件”。

通过标准：确实缺依赖 → 下载 → 安装组件 → 检测通过 → FoxMouse 安装 → 正常启动。仅打开安装器、下载成功或离线包安装成功都不能替代。

## 三、功能与界面验收

| 编号 | 操作 | 预期结果 |
|---|---|---|
| A1 倍率输入 | 输入 4、4.25，保存并重开；再分别输入 9、0、字母，清空后按 Tab | 数字不遮挡；4 无多余零；9 限制为 6、0 限制为 1.5；非法值不保存；空值恢复之前有效值 |
| A2 静止光标 | 预览和摇动触发各重复约 20 次；效果结束后手离开鼠标至少 5 秒；在不同应用重复 | 恢复原大小后光标仍可见，不需要移动唤回；无重复光标或残影 |
| A3 应用屏蔽 | 左栏搜索一个应用并添加；右栏搜索、取消屏蔽；保存重开；搜索后切到常规再返回 | 左应用列表、右已屏蔽；搜索与列表一致；不重复添加；设置保存；切页后搜索词与筛选结果一致 |
| A4 屏蔽生效 | 将一个普通应用加入名单，切到该应用前台再摇动；切回其他未屏蔽应用 | 被屏蔽应用前台暂停效果，切回未屏蔽应用恢复 |
| A5 托盘退出 | 设置中产生未保存修改，从托盘退出；分别测试“保存并退出”“不保存”“取消” | 等待选择；三种选择都按本项目约定退出后台和设置，只有保存选项保存修改。普通关闭设置时“取消”仍应留在设置页 |
| A6 定位环 | 在深浅背景分别触发定位环 | 无白色描边、残留方框或明显锯齿；结束后消失 |
| A7 语言与主题 | 切换中英文，保存重开；切换系统浅色/深色；检查托盘、设置、关于和安装器 | 文案完整、语言保存、Logo 对比度正确、文字不裁切；应用名称/进程名不要求翻译 |
| A8 布局与键盘 | 缩窄窗口、查看长应用名；用 Tab/回车操作搜索和添加 | 左右栏可用，按钮不重叠，长名称不挤掉操作按钮，焦点可见 |
| A9 保存提示 | 修改设置并保存，保持窗口打开 | 提示无绿色背景和关闭按钮，约 10 秒自动消失 |
| A10 多屏与动画 | 若有多屏，在不同缩放、不同刷新率屏幕之间移动并触发；观察缩小结束 | 跟随位置正确，无明显跳变、模糊或残影，缩小平滑；没有 8K 设备时 8K 填未测 |

A2 若失败，请注明“预览”还是“摇动”，效果模式、次数、前台应用、是否拖拽/全屏、哪台显示器。不要因一次正常就判断永久不会失效。

## 四、维护与卸载（优先虚拟机）

1. 同版本重跑安装器，执行修复，确认设置保留，结束后维护窗口退出。
2. 检查安装根目录存在 FoxMouse.Uninstall.exe。
3. 在 Windows 设置 → 应用中搜索 FoxMouse，确认可以启动卸载；另用快照测试根目录卸载器入口。
4. 卸载页应单页完整显示，确认按钮有效；退出 FoxMouse 并恢复系统光标后删除应用文件与应用注册。
5. 分别验证保留设置/删除设置选项；只在可丢弃环境测试删除设置。
